# 🔍 FakeNet Detector

Веб-приложение для выявления фейковых аккаунтов на основе анализа графа социальных связей и поведенческой активности пользователей.

## Стек технологий

- **Backend:** Python 3.11, Flask, Flask-SocketIO
- **База данных:** SQLite
- **ML:** scikit-learn (Isolation Forest)
- **Граф:** NetworkX, python-louvain
- **Frontend:** HTML5 Canvas, Vanilla JS, Jinja2
- **VK API:** requests

## Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/your-username/fakenet-detector.git
cd fakenet-detector

# Установить зависимости
pip install flask flask-socketio networkx python-louvain pandas numpy scikit-learn scipy requests

# Запустить
python app.py
```

Открыть в браузере: `http://127.0.0.1:5000`

Аккаунт администратора: `admin` / `admin123`

## Разделы приложения

### Лента
Главная страница социальной сети. Пользователи могут:
- Публиковать посты
- Ставить лайки и писать комментарии
- Подписываться на других пользователей
- Запускать симулятор ботов — боты начинают автономно генерировать активность

### Граф
Интерактивная визуализация социального графа на HTML5 Canvas:
- **Зелёные узлы** — легитимные аккаунты
- **Красные узлы** — подозрительные (выявлены алгоритмом)
- Физический движок расставляет узлы автоматически, узлы можно перетаскивать мышкой
- При наведении на узел — всплывающая карточка со статистикой
- Кнопка **«Обновить граф»** — запускает повторный анализ
- Кнопка **«Отчётность»** — открывает детальный отчёт по подозрительным аккаунтам с метриками активности
- Кнопка **«Сбросить граф»** (только для админа) — очищает активность ботов и возвращает граф в исходное состояние

### VK Анализ
Анализ реальных профилей ВКонтакте по ссылке:
- Вставить ссылку на профиль VK и токен доступа
- Алгоритм анализирует публичные данные: фото, друзья, посты, подписки, заполненность профиля
- Выдаёт балл подозрительности от 0 до 100 и список признаков
- История проверок сохраняется между сессиями

### Панель администратора
Доступна только пользователю `admin`:
- **Статистика** — общее число пользователей, ботов, постов и подписок
- **Глобальное управление** — запустить или остановить симулятор для всех аккаунтов
- **Аномальный режим** — случайно выбирает 2 аккаунта и запускает их в режиме максимальной подозрительности (ночная активность, burst-лайки, спам). После перехода в Граф и обновления — эти аккаунты гарантированно выделяются красным
- **Таблица пользователей** — управление каждым аккаунтом по отдельности: запуск/остановка симулятора, удаление

## Структура проекта

├── database.py             # SQLite, все операции с данными
├── graph_engine.py         # Построение графа, метрики NetworkX

├── visualizer.py           # HTML-визуализация через pyvis

│   ├── index.html          # Лента
│   ├── graph.html          # Граф
│   ├── admin.html          # Панель администратора
│   ├── vk.html             # VK Анализ
